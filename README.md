## Структура

- `server.js` - запуск сервера та підключення до бази
- `models/` - схеми MongoDB: контакт і група
- `routes/contacts.js` - API контактів і кошика
- `routes/groups.js` - API груп
- `routes/mailing.js` - надсилання розсилки
- `public/index.html` - сторінка
- `public/js/contacts.js` - уся робота сторінки з сервером
